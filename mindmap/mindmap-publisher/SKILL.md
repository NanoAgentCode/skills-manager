# Mindmap Publisher

## Overview

Use this skill only after a mindmap has already been generated by `mindmap-builder` or an equivalent process. This skill copies `index.html` plus `markmap-assets/` into a static publishing directory and returns the corresponding HTTP(S) URL.

Do not use this skill for local double-click HTML output. Use `mindmap-builder` for that.

## Required Inputs

Before publishing, require all of these values:

- `SourceHtml`: path to the generated mindmap HTML file.
- `StaticRoot`: server/static directory that maps to the public URL path.
- `PublicBaseUrl`: public origin, for example `https://example.com`.
- `PathPrefix`: required URL path prefix, for example `/mindmaps`. Do not default, infer, or leave empty.
- `Slug`: destination folder name under the path prefix, for example `zero-trust-ai-agents`.

If `PathPrefix` is missing, stop and ask for it. Publishing without a path prefix is not allowed.

## Publishing Model

Expected source:

```text
source/
  output.html
  markmap-assets/
    d3.min.js
    markmap-view.js
    markmap-toolbar.js
    markmap-toolbar.css
```

Published result:

```text
{StaticRoot}/{Slug}/
  index.html
  markmap-assets/
    d3.min.js
    markmap-view.js
    markmap-toolbar.js
    markmap-toolbar.css
```

Returned URL:

```text
{PublicBaseUrl}{PathPrefix}/{Slug}/index.html
```

## Workflow

1. Confirm explicit user intent:
   - Continue only if the user says publish, deploy, host, expose, preview URL, server URL, or similar.
   - Otherwise, recommend `mindmap-builder` local HTML output.
2. Collect required inputs:
   - Refuse to publish if `PathPrefix` is absent or `/`.
   - Normalize `PathPrefix` to start with `/` and have no trailing `/`.
   - Normalize `PublicBaseUrl` to have no trailing `/`.
   - Validate `Slug` uses only letters, digits, hyphens, underscores, or dots.
3. Verify source:
   - `SourceHtml` exists.
   - Source sibling `markmap-assets/` exists.
   - HTML does not contain `cdn.jsdelivr.net`.
4. Publish:
   - Use `scripts/publish_mindmap.ps1`.
   - Copy HTML as `index.html`.
   - Copy `markmap-assets/` into the destination.
   - Do not modify unrelated files.
5. Verify:
   - Destination `index.html` exists.
   - Destination assets exist.
   - Returned URL includes the required `PathPrefix`.

## Script

Use:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish_mindmap.ps1 `
  -SourceHtml .\output.html `
  -StaticRoot D:\nginx\html\mindmaps `
  -PublicBaseUrl https://example.com `
  -PathPrefix /mindmaps `
  -Slug zero-trust-ai-agents
```

The script returns JSON containing:

```json
{
  "published_dir": "...",
  "index_file": "...",
  "url": "https://example.com/mindmaps/zero-trust-ai-agents/index.html"
}
```

## Deployment Notes

Read `references/nginx-static-publish.md` when the user needs help matching `StaticRoot`, `PublicBaseUrl`, and `PathPrefix` to an Nginx `location` or `alias` config.

This skill does not configure Nginx automatically. It publishes files to a configured static directory and computes the URL from user-provided deployment settings.
