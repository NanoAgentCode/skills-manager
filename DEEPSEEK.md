# DeepSeek Compatibility Entry

Use this repository as a skills library.

DeepSeek may not auto-load skills from this directory, so use explicit reading when needed:

```text
Read AGENTS.md, choose the relevant skill, then read <skill-path>/SKILL.md and follow it.
```

Execution rules:

1. Prefer `SKILL.md` over README prose when there is a conflict.
2. Load referenced resources only when needed.
3. Prefer bundled scripts for repeatable operations.
4. Keep real credentials private and use example configs only for documentation.
5. Translate shell commands to the current runtime when PowerShell is unavailable.

For Chinese tasks, answer in Chinese unless the user requests otherwise.
